토토레드 데스크톱 우선 프로토타입 V4

핵심 수정
- 데스크톱 우선 3영역 레이아웃: (선택) 좌측 광고 / 중앙 메인 / 우측 정보 패널
- 좌측 광고가 없으면 열 자체를 제거하고 중앙 메인 폭을 자동 확장
- 상단 토토레드 로고와 입점문의 이미지를 HTML 안에 직접 포함(단일 index.html 업로드 가능)
- 홈 메뉴 및 각 개별 메뉴 화면 전환
- 관리자 페이지에서 이미지 파일 직접 선택, 링크·노출 페이지·위치 설정, 추가·삭제·순서 변경
- 광고 데이터는 localStorage에 저장되는 데모 방식

테스트
1. index.html을 Chrome 또는 Edge에서 직접 엽니다.
2. 관리자 메뉴 → 배너 제목 입력 → 이미지 파일 선택(선택) → 배너 추가
3. 홈 메뉴로 이동해 배너가 중앙 열에 배치되는지 확인합니다.
4. 로고 클릭 시 홈으로 이동하는지 확인합니다.

GitHub Pages 배포
- 이 패키지는 단일 파일로도 구동됩니다. index.html을 저장소 최상위(root)에 업로드하세요.
- 로고와 입점문의 이미지가 index.html 내 data URI로 포함되어 assets 폴더가 없어도 깨지지 않습니다.

유의
- 화면 및 브라우저 내 광고 설정 저장을 확인하는 프로토타입입니다. 실제 회원 인증, 서버 DB, 광고 결제·정산, 노출 통계는 아직 연동되지 않았습니다.
- 실제 광고는 관련 법령을 준수하는 합법적인 상품·서비스에 한해 게시해야 합니다.
