토토레드 웹사이트 프로토타입 V3

실행: index.html 파일을 Chrome 또는 Edge에서 엽니다.
GitHub Pages: index.html과 assets 폴더를 저장소 루트에 업로드합니다.

이번 수정 사항
- 헤더 로고를 승인된 토토레드 로고 이미지로 교체
- 로고 클릭 시 홈으로 이동
- 메인 바로가기 카드 제거
- 공지사항 바로 아래 광고 배너 그리드 배치
- 데스크톱 3열 레이아웃 및 우측 정보 영역 적용
- 관리자 페이지에서 메인 광고와 좌측 세로 광고 공간을 추가할 수 있도록 구성
- 배너 데이터는 브라우저 localStorage 데모 저장

주의: 실제 회원 인증, 서버 DB, 결제, 실제 광고 정산은 미연결 상태입니다.
